# Sales Analytics Dashboard

## Descripción
Proyecto de análisis de ventas minoristas utilizando SQL Server y Power BI.

## Objetivos
- Limpiar y transformar datos de ventas.
- Analizar el comportamiento de clientes.
- Identificar categorías con mejor rendimiento.
- Construir KPIs para la toma de decisiones.

## Herramientas Utilizadas
- SQL Server
- Power BI
- Excel

## KPIs Principales
- Ventas Totales
- Total de Clientes
- Total de Transacciones
- Ticket Promedio

## Análisis Realizados
- Limpieza de datos
- Detección de duplicados
- Transformación de variables
- Evolución mensual de ventas
- Ventas por categoría
- Segmentación de clientes
